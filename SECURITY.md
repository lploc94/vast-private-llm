# Security policy

## Supported versions

Security fixes are considered for the current `main` branch. There is no long-term maintenance promise for older commits.

## Reporting a vulnerability

Use **Report a vulnerability** under the repository's [Security advisories](https://github.com/lploc94/vast-private-llm/security/advisories) to send a private report to the maintainers. Include the affected commit, reproduction steps, and impact. Please do not publish credentials or exploit details in a public issue.

This application is designed for a dashboard bound to `127.0.0.1`. It does not authenticate remote administrators. A report should state whether it requires the dashboard to be exposed outside that supported configuration.
