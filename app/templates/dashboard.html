Chat completion

POST /v1/chat/completions · Header Authorization: Bearer YOUR_USER_KEY

Response ví dụ (rút gọn)

{
  "model": "qwen-3.8",
  "choices": [{
    "message": {"role": "assistant", "content": "Xin chào!"},
    "finish_reason": "stop"
  }]
}

Danh sách model

GET /v1/models

Đổi YOUR_USER_KEY thành key của user. Thêm "stream": true vào JSON để nhận phản hồi từng phần. Key sai nhận 401; model chưa sẵn sàng nhận 503.
